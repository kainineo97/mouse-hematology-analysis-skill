# GraphPad Prism 粘贴表

当用户要求“可直接复制到 GraphPad/Prism”时使用本规范。每个指标输出一张 XY 百分比表，不混合不同指标。

## 表结构

- 第一列是 X，标题为 `Time (days)`；数据优先使用配置中的 `timepoints[].day`。若未提供可解析的数值，则使用该采集日期与基线采集日期的天数差。
- 每个实验组是一个 Y 数据集。若配置提供 `group_order`，严格按该顺序从左到右排列；否则按初始动物登记表中组别首次出现的顺序。`group_order` 必须完整且不重复地列出所有组。
- 动物是并排重复子列，并按登记表顺序固定位置；同一动物在所有时间点保持同一列，便于重复测量连线和追踪。
- 所有组使用相同的重复子列数，取最大组的初始动物数；较小分组尾部补空列。
- 第一行在每个组块的首列写组名，其余子列留空；第二行写 `X` 和动物 ID；第三行起是数据。
- 一个输入时间点只产生一行数据；多个时间点按配置顺序各产生一行，不拆成不同动物顺序的表。

示意：

```text
Time (days)  PBS             Drug
X            10      11      20      21
0            100.00  100.00  100.00  100.00
1            95.24   65.38   177.14
3            119.05  84.62
```

## 数值与空白

- 使用当前分析口径的百分比字段；若样本有稀释记录，先做 `corrected = raw × dilution_factor`，默认再计算 `%D0 = corrected_current / corrected_D0 × 100`。若用户选择相对变化率则使用基于校正值的 `delta_pct_D0`。
- 默认口径下，有效 D0 显示 `100.00`；相对变化率口径下显示 `0.00`。
- `DEAD`、`MISSING_SAMPLE`、`MISSING_METRIC`、`NON_NUMERIC`、`DUPLICATE_SAMPLE`、`POST_DEATH_DATA`、D0 缺失和 D0=0 均留空。不得写 0、`NA`、短横线或插补值。
- TSV 百分比保留两位小数，使用句点作为小数点。

## 粘贴到 Prism

在 Prism 新建 XY 表，选择“replicate values in side-by-side subcolumns”，Y 数据集数设为组数，重复子列数设为最大组初始动物数。将数据区从第一列 X 开始粘贴；前两行用于核对组名和动物子列。工作簿中的 `GraphPad <metric>` 表应保持相同矩形布局，不在数据块内加入额外说明。
